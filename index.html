Cara Main

Mode Main

• Solo: Main di satu perangkat. Cocok untuk ngobrol santai berdua atau grup kecil.

• Multiplayer: Gunakan satu perangkat sebagai Host (Layar Utama) dan pemain lain gabung sebagai Guest menggunakan HP masing-masing.

Cara Bermain

• Deep Talk: Jawab pertanyaan dengan jujur dan terbuka. Ini adalah momen untuk saling mengenal lebih dalam.

• Multiplayer: Di mode party, setiap pemain akan bergantian terpilih secara acak (ditandai layar Hijau di HP mereka) untuk menjawab pertanyaan yang muncul di layar utama.

Sistem multiplayer menggunakan sistem antrean adil agar semua orang mendapatkan giliran berbicara.
